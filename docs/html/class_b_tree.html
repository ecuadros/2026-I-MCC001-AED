Detailed Description

template<typename Traits>
class BTree< Traits >

Contenedor principal del árbol B.

Esta clase representa el árbol B completo y se apoya internamente en CBTreePage para manejar cada página. Aquí también agregué iteradores forward/backward, concurrencia con mutex y la reutilización de los algoritmos globales ForEach y FirstThat.
