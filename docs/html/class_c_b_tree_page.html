Detailed Description

template<typename Traits>
class CBTreePage< Traits >

Página interna del árbol B.

Una página agrupa varias claves y varios punteros a subpáginas. En esta clase se resuelve la lógica estructural del árbol B: insertar, partir páginas, fusionar páginas y redistribuir elementos.
