Detailed Description

Implementación de la página interna del árbol B.

En este archivo se maneja la lógica interna de cada página del árbol B: inserción, eliminación, redistribución, merge, split y acceso a nodos extremos para los iteradores. Esta clase no es el contenedor final, sino la estructura interna sobre la que se apoya BTree.
